# Task 2: NLP Sentiment Classification on Customer Reviews
**Notebook:** `NLP_Sentiment_Classification.ipynb`

# Objective
Classify customer reviews into three sentiment categories: positive, negative, and neutral.

# Technologies Used
- Python
- Pandas and NumPy
- NLTK
- Scikit-learn
- TF-IDF Vectorization
- Multinomial Naive Bayes
- Logistic Regression

# Workflow
1. Load and explore the customer review dataset.
2. Clean and preprocess review text.
3. Convert text into numerical features using TF-IDF.
4. Train machine learning models.
5. Evaluate model performance.
6. Predict sentiment for new reviews.

# Dataset
The sample dataset contains 10 customer reviews labeled as positive, negative, or neutral.

**Note:** The dataset is small, so results are for demonstration purposes only.
