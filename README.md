 # NLP Sentiment Classification on Customer Reviews #

# Project Overview
This project uses Natural Language Processing (NLP) and machine learning to classify customer reviews as positive, negative, or neutral.

# Technologies Used
- Python
- Pandas and NumPy
- NLTK
- Scikit-learn
- TF-IDF Vectorization
- Multinomial Naive Bayes
- Logistic Regression

# Project Workflow
1. Load and explore customer review data.
2. Clean and preprocess review text.
3. Convert text into numerical features using TF-IDF.
4. Train Naive Bayes and Logistic Regression models.
5. Evaluate model performance.
6. Predict sentiment for new customer reviews.

# Dataset
The sample dataset contains 10 customer reviews labeled as positive, negative, or neutral.

*Note:* The dataset is small, so the model results are for demonstration purposes only.

# How to Run
Open `NLP_Sentiment_Classification.ipynb` in Google Colab and run the notebook cells in order.
